# To-Do Desktop Application

Простий, швидкий та інтуїтивно зрозумілий десктопний застосунок для планування щоденних справ і керування завданнями. Проєкт створено на базі мови програмування Python із використанням графічної бібліотеки Tkinter у межах вивчення методологій тестування та забезпечення якості ПЗ (SQE).

---

## ✨ Ключові можливості (Features)

* **Додавання завдань:** Швидке введення тексту справи через інтерактивне текстове поле без обмежень на довжину.
* **Видалення елементів:** Можливість миттєво видалити будь-яке виділене завдання зі списку.
* **Локальне збереження:** Автоматичний або ручний запис усіх поточних справ у текстовий файл на диску. Дані завантажуються під час наступного старту програми.
* **Надійність коду:** Логіка програми повністю покрита автоматизованими тестами за допомогою вбудованого модуля `unittest` та сучасного фреймворку `pytest`.

## 🛠️ Встановлення та запуск (Installation & Usage)

### 1. Клонування репозиторію
Складіть локальну копію проєкту на своєму комп'ютері:
```bash
git clone [https://github.com/ваш-юзернейм/SQE-lab2.git](https://github.com/ваш-юзернейм/SQE-lab2.git)
cd SQE-lab2
```

### 2. Запуск програми
У проєкті реалізовано автоматичне покриття тестами для перевірки стабільності функцій додавання, видалення та збереження файлів.
Якщо ви хочете запустити тестові сценарії, використовуйте команду:
```bash
python -m pytest -v
```
